# React: делаем свой первый сайт

Методичка для тех, кто никогда не делал сайты на React. Идёте по пунктам сверху вниз, и в конце у вас на компьютере открывается маленький одностраничный сайт на адресе `localhost`.

Вот такой сайт у вас получится в конце:

![Готовый сайт](docs/img/result.png)

## Для кого этот курс

Для новичков. Не нужно знать React, Node.js или Git. Достаточно уметь пользоваться компьютером и примерно представлять, что сайт состоит из текста, картинок и кнопок. Если вы когда-то видели HTML, будет проще, но это не обязательно: все теги разбираются по ходу.

## Что понадобится

- Компьютер с Windows, macOS или Linux и около часа свободного времени.
- VS Code, редактор кода.
- Node.js вместе с NPM, чтобы запускать проект.
- Git (вместе с ним ставится Git Bash), чтобы выложить проект на GitHub.
- Аккаунт на GitHub.
- Интернет для установки пакетов.

## Как запустить готовый пример

Нужны уже установленные Node.js и NPM (раздел 2). В папке `coffee-site` выполните:

```
npm install
npm run dev
```

После этого откройте в браузере адрес, который напишет терминал. Обычно это http://localhost:5173.
