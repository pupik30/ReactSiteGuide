# 6. Итоги

Если вы дошли сюда и у вас открывается сайт на localhost, поздравляю: вы сделали первый проект на React.

## Чему вы научились

- Устанавливать VS Code, Node.js, NPM и Git, и понимать, зачем каждая из этих программ нужна.
- Пользоваться VS Code: терминал, каталог, хоткеи, масштаб, темы.
- Создавать проект на React командой `npm create vite@latest` и запускать его командой `npm run dev`.
- Писать разметку на JSX, знать основные теги (`header`, `main`, `section`, `div`, `p`, `img`, `button`, `ul`, `footer`) и правила JSX.
- Делить сайт на компоненты и передавать им данные через props.
- Выводить списки через `map` и не забывать про `key`.
- Хранить состояние через `useState` и реагировать на нажатие кнопки.
- Стилизовать через SCSS: переменные, вложенность, `@use`, адаптив через `@media`.
- Загружать проект на GitHub через VS Code и обновлять его.

## Что делать дальше

1. Сделайте второй сайт на свою тему, не подглядывая. Пусть он будет хуже, зато ваш.
2. Прочитайте официальную документацию React на русском, раздел «Быстрый старт»: https://ru.react.dev
3. Освойте то, чего здесь не было: формы и поля ввода, несколько страниц через React Router, запросы к API через `fetch`, хук `useEffect`.
4. Научитесь выкладывать сайт в интернет. Для учебных сайтов подходят GitHub Pages, Netlify или Vercel, они бесплатны для начала.

## Памятка команд

- `npm create vite@latest имя -- --template react` создать новый проект.
- `npm install` скачать библиотеки проекта.
- `npm install -D sass` добавить пакет в проект.
- `npm run dev` запустить сайт на localhost.
- `npm run build` собрать готовую версию в папку `dist`.
- `Ctrl + C` в терминале остановить сервер.
