# 5. Что такое GitHub и как залить проект из VS Code

## Что это такое

**Git** это программа на вашем компьютере, которая запоминает историю изменений проекта. Каждое сохранённое состояние называется **коммитом**. Если что-то сломали, можно вернуться к рабочей версии.

**GitHub** это сайт, куда Git отправляет копию вашего проекта. Это и резервная копия, и портфолио (его можно показать работодателю), и способ работать над кодом вместе с другими.

Место проекта на GitHub называется **репозиторием** (repository, сокращённо repo).

Если коротко: Git живёт у вас на компьютере, GitHub живёт в интернете, и между ними вы отправляете коммиты.

## Что нужно заранее

- Установленный Git (раздел 2) и выполненные команды `git config --global user.name` и `user.email`.
- Аккаунт на GitHub.
- Готовый проект, открытый в VS Code.

В проекте от Vite уже есть файл `.gitignore`. Он говорит Git не отправлять тяжёлую папку `node_modules` и другие лишние файлы. Не удаляйте его. Папка `node_modules` восстанавливается любым, кто скачал проект, командой `npm install`.

## Способ 1. Через VS Code

1. Слева нажмите значок **Source Control** (ветка с кружками) или `Ctrl + Shift + G`.
2. Нажмите кнопку **Initialize Repository** (Инициализировать репозиторий). Теперь папка проекта под контролем Git. Список файлов ниже называется изменениями.
3. В поле **Message** напишите короткое описание, например `Первая версия сайта`.
4. Нажмите **Commit** (галочка). Если VS Code спросит, не добавить ли все изменения, ответьте «Да» (Always). Коммит создан, но пока лежит только у вас.
5. Нажмите **Publish Branch** (Опубликовать ветку). VS Code предложит войти в GitHub, откроется браузер, нажмите «Authorize» и разрешите доступ.
6. Выберите название репозитория (латиницей, например `my-react-site`) и тип: **public** (виден всем) или **private** (только вам).
7. Подождите, пока всё загрузится. В правом нижнем углу появится уведомление «Open on GitHub». Нажмите, и откроется страница вашего проекта в интернете.

## Способ 2. Через терминал (Git Bash)

Тот же результат, только командами. Сначала на сайте github.com нажмите «New repository», придумайте название и создайте репозиторий **пустым** (без галочек «Add a README» и прочего). GitHub покажет адрес вида `https://github.com/ваш-ник/my-react-site.git`.

Затем в терминале VS Code, находясь в папке проекта:

```
git init
git add .
git commit -m "Первая версия сайта"
git branch -M main
git remote add origin https://github.com/ваш-ник/my-react-site.git
git push -u origin main
```

Что делает каждая команда:

- `git init` создаёт репозиторий на вашем компьютере.
- `git add .` отмечает все изменённые файлы для следующего коммита. Точка значит «все».
- `git commit -m "..."` записывает коммит с вашим сообщением.
- `git branch -M main` называет главную ветку `main`.
- `git remote add origin ...` связывает папку с репозиторием на GitHub.
- `git push -u origin main` отправляет коммиты в интернет.

## Как отправлять новые изменения

После первой загрузки процесс всегда один и тот же:

1. Поправили код, сохранили (`Ctrl + S`).
2. Source Control, написали сообщение, нажали **Commit**.
3. Нажали **Sync Changes** (синхронизировать).

Или командами:

```
git add .
git commit -m "Что я изменил"
git push
```

Сообщения коммитов лучше писать по делу: «Добавил карточку напитка», а не «ааа» и не «правки».

## Частые проблемы

- **Просит логин и пароль в терминале.** GitHub не принимает обычный пароль для git. Проще всего использовать Способ 1 с входом через браузер.
- **Ошибка «Author identity unknown».** Не выполнили `git config --global user.name` и `user.email` из раздела 2.
- **Ошибка «remote origin already exists».** Связь уже добавлена. Проверьте адрес командой `git remote -v`.
- **В репозитории оказалась папка node_modules.** Скорее всего, пропал `.gitignore`. Верните его, удалите папку из репозитория и сделайте новый коммит.
