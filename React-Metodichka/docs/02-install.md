# 2. Установка нужного ПО

Нужно поставить четыре вещи. Ставьте в том порядке, как написано, на все вопросы установщиков можно отвечать «Далее» (Next), если ниже не сказано иначе.

## VS Code

Редактор, в котором мы будем писать код. Подсвечивает синтаксис, подсказывает названия, имеет встроенный терминал.

Скачать: https://code.visualstudio.com

Во время установки на Windows полезно поставить галочки «Add to PATH» и «Open with Code» (добавить в контекстное меню).

## Node.js и NPM

Node.js запускает JavaScript вне браузера, NPM скачивает библиотеки. Ставятся вместе.

Скачать: https://nodejs.org

Берите версию с пометкой **LTS** (долгосрочная поддержка). Не берите «Current», она новее, но менее стабильная.

Проверка, что всё встало. Откройте терминал (на Windows это PowerShell или Git Bash) и введите по очереди:

```
node -v
npm -v
```

Если в ответ вы видите номера версий (например `v22.12.0` и `10.9.0`), всё в порядке. Если пишет, что команда не найдена, закройте терминал, откройте заново, а если не помогло, перезагрузите компьютер.

## Git и Git Bash

Git хранит историю изменений проекта и нужен, чтобы отправлять код на GitHub. Вместе с Git на Windows ставится Git Bash, это удобный терминал, в котором работают привычные команды.

Скачать: https://git-scm.com/downloads

Во время установки всё можно оставить по умолчанию.

Проверка:

```
git --version
```

Сразу же один раз представьтесь Git, подставив своё имя и почту (ту же, что на GitHub):

```
git config --global user.name "Ваше Имя"
git config --global user.email "you@example.com"
```

## Аккаунт на GitHub

GitHub это сайт, где хранится код в интернете. Зарегистрируйтесь: https://github.com

Он понадобится в разделе 5.

## Рекомендую поставить в VS Code

Это необязательно, но жизнь станет проще. В VS Code слева есть значок «Расширения» (Extensions, четыре квадратика), ищите по названию:

- **Russian Language Pack** переводит интерфейс на русский.
- **ES7+ React/Redux/React-Native snippets** даёт быстрые заготовки, например `rfce`.
- **Prettier - Code formatter** выравнивает код сам.
