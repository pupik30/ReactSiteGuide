# Кофейня «Зерно» - готовый сайт из методички

Одностраничный сайт на React + SCSS (сборщик Vite).

```
npm install
npm run dev
```

Откройте http://localhost:5173 (точный адрес покажет терминал).

Структура:

- `src/App.jsx` - главный компонент, хранит число товаров в корзине.
- `src/components/` - Header, Hero, About, Menu, Footer (каждый с .scss).
- `src/data/menu.js` - данные меню.
- `src/styles/_variables.scss` - цвета и размеры.
- `src/assets/` - картинки (SVG).
