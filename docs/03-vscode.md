# 3. Помощь с окружением в VS Code

Здесь знакомимся с редактором и готовим пустой проект. Код пока не пишем.

## Первый запуск и тема

Откройте VS Code. Чтобы выбрать тему оформления, нажмите `Ctrl + K`, затем отпустите и нажмите `Ctrl + T` (на Mac `Cmd + K`, `Cmd + T`). Появится список, стрелками вверх и вниз можно листать и сразу видеть, как меняется вид. Выберите ту, на которую приятно смотреть. Для долгой работы чаще берут тёмные.

Все настройки лежат по шестерёнке слева внизу, либо через `Ctrl + ,`.

## Как приблизить и отдалить

Если текст мелкий или, наоборот, огромный, есть два способа.

- Весь интерфейс целиком: `Ctrl + =` приблизить, `Ctrl + -` отдалить, `Ctrl + 0` вернуть как было (на Mac `Cmd`).
- Только размер букв в коде: в настройках (`Ctrl + ,`) найдите «Font Size» и поставьте число, например 16 или 18. Либо зажмите `Ctrl` и покрутите колёсико мыши, если эта опция включена (в настройках она называется «Mouse Wheel Zoom»).

## Что где находится

Окно VS Code состоит из нескольких зон:

- **Слева узкая полоска со значками** переключает режимы: проводник (файлы), поиск, Git, расширения.
- **Каталог (проводник, Explorer)** это список папок и файлов вашего проекта. Открывается через `Ctrl + Shift + E`.
- **Рабочая область** это большая центральная часть, где открываются файлы с кодом. Файлы открываются вкладками сверху.
- **Терминал** это окно с командной строкой внизу. Открывается через `Ctrl + ` (обратная кавычка, кнопка слева от единицы) или через меню «Терминал, Создать терминал».
- **Строка состояния** самая нижняя синяя полоса: там ветка Git, ошибки, язык файла.

Панель слева можно спрятать и показать обратно через `Ctrl + B`, если не хватает места.

## Хоткеи, которые пригодятся

- `Ctrl + S` сохранить файл. Делайте это постоянно: сайт обновляется только после сохранения. Или File > Auto Save.
- `Ctrl + P` быстро открыть файл по названию.
- `Ctrl + Shift + P` палитра команд, через неё можно найти любое действие по названию.
- `Ctrl + /` закомментировать или раскомментировать строку.
- `Alt + вверх` или `Alt + вниз` переместить строку.
- `Shift + Alt + вниз` скопировать строку вниз.
- `Ctrl + D` выделить следующее такое же слово, удобно для массового переименования.
- `Ctrl + Z` отменить, `Ctrl + Shift + Z` вернуть.
- `Ctrl + Shift + F` поиск по всему проекту.

## Подготовка окружения для проекта

1. Создайте на компьютере папку, где будут жить ваши проекты, например `projects`.
2. В VS Code выберите «Файл, Открыть папку» и откройте её.
3. Откройте терминал (`Ctrl + ` `).

## Создаём проект на React

Мы используем Vite. Это инструмент, который готовит пустой проект и запускает быстрый локальный сервер. Введите в терминале:

```
npm create vite@latest 
```
Выбираем React, JavaScript, Oxline, Остальное по умолчанию

```
cd my-site
npm install
```

`npm install` читает файл `package.json`, где перечислено, что нужно проекту, и скачивает всё это в папку `node_modules`. Папка получится тяжёлая, это нормально.

Ещё нам нужен SCSS (это удобный способ писать стили). Для него ставится пакет `sass`:

```
npm install -D sass
```

Флаг `-D` означает, что пакет нужен только на время разработки.

Теперь откройте проект в VS Code именно как папку проекта: «Файл, Открыть папку», выберите `my-site`. Дальше всё делаем уже там.

## Запускаем

```
npm run dev
```

В терминале появится что-то такое:

```
  VITE ready in 300 ms
  ➜  Local:   http://localhost:5173/
```

Зажмите `Ctrl` и нажмите на адрес, либо вставьте его в браузер. Должна открыться стартовая страница Vite и React с вертящимся логотипом и счётчиком. Это ваш первый localhost.

Остановить сервер можно в терминале сочетанием `Ctrl + C`. Запустить снова командой `npm run dev`.

## Из чего состоит проект

Откройте каталог слева. Нас интересует главное:

- `index.html` единственная HTML-страница. В ней пустой `<div id="root">`, в который React рисует весь сайт.
- `src/` папка, в которой мы будем работать.
- `src/main.jsx` точка входа, подключает React к странице.
- `src/App.jsx` главный компонент, с него начнём.
- `public/` сюда кладут файлы, которые отдаются как есть, например иконку сайта.
- `package.json` паспорт проекта: название, команды запуска, список библиотек.
- `node_modules/` скачанные библиотеки. Её не трогаем и не выкладываем на GitHub.
