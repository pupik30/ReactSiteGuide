React — это популярная JavaScript-библиотека с открытым исходным кодом для разработки динамичных и быстрых пользовательских интерфейсов.

Главная идея React — компоненты. Компонент можно представить как независимый и изолированный кирпичик (блок), внутри которого находится всё необходимое для работы конкретной части интерфейса:

• структура (HTML-разметка через JSX);
• логика (функции и обработчики событий на JavaScript);
• стили (внешний вид этой части интерфейса).
Эти кирпичики изолированы друг от друга: кнопка, форма авторизации или шапка сайта живут своей жизнью, но при этом могут легко обмениваться данными. Благодаря этому код React-приложений собирается быстрее, его проще масштабировать, а интерфейс работает молниеносно по сравнению со старыми сайтами на чистом HTML.

## Какую задачу решает  React

Создание интерактивных сайтов на чистом JavaScript часто превращается в хаос: приходится вручную искать элементы на странице, следить за изменением данных и обновлять каждый кусочек интерфейса отдельно. React избавляет от этой рутины. 

Типичные сценарии:

• Создавать переиспользуемые элементы: один раз написать код красивой кнопки или карточки товара и вставлять её в любые части сайта;
• Мгновенно обновлять данные: делать живой поиск, динамические корзины покупок и чаты без перезагрузки всей страницы видя результат сразу;
• Управлять сложным интерфейсом: легко связывать между собой десятки независимых блоков нажатие кнопки в одном блоке меняет цвет или целую структуру в другом блоке.

## Базовые понятия

Перед установкой достаточно запомнить четыре слова:

• HTML — язык разметки, который создает каркас и структуру веб-страницы (текст, кнопки, списки).

• CSS — язык стилей, который отвечает за внешний вид сайта (цвета, шрифты, отступы и расположение элементов).

• VSC — удобный текстовый редактор (Visual Studio Code), в котором пишется и редактируется весь код проекта.

• GitHub — онлайн-платформа, где хранится ваш код, отслеживаются его изменения и ведется совместная разработка. Там мы будем хранить наш проект

• Node.js — это среда выполнения языка JavaScript, которая работает вне веб-браузера и позволяет запускать код на сервере

## Первая проверка

Откройте терминал и выполните:

```bash
docker version
```

В выводе должны появиться сведения о клиенте (`Client`) и сервере (`Server`). Если блок `Server` пустой или команда не находится, Docker Desktop ещё не запущен либо установка не завершена.

Затем запустите учебный контейнер:

```bash
docker run hello-world
```

Что происходит:

1. Docker ищет образ `hello-world` локально.
2. Если образа нет, он скачивается с Docker Hub.
3. Из образа создаётся контейнер.
4. Контейнер печатает приветствие и завершается.

Сообщение вроде `Hello from Docker!` означает, что установка прошла успешно.

Полезные команды рядом:

```bash
docker images
docker ps -a
```

`docker images` показывает скачанные образы. `docker ps -a` показывает все контейнеры, включая уже остановленные. Контейнер `hello-world` после печати сообщения останавливается — это нормально.

## Практика

1. Установите Docker (Desktop на Windows и macOS или Engine на Linux) и дождитесь запуска движка.
2. Выполните `docker version` и убедитесь, что есть и Client, и Server.
3. Выполните `docker run hello-world`.
4. Посмотрите список образов и контейнеров командами выше.
5. Сформулируйте своими словами: чем образ отличается от контейнера.

## Кратко

- Docker запускает приложения в контейнерах — изолированных «коробках» с кодом и зависимостями.
- Контейнер легче виртуальной машины, потому что делит ядро с хостом.
- Образ — шаблон, контейнер — его запущенная копия.
- Если `docker run hello-world` работает, можно переходить к следующим урокам: образы, Dockerfile и собственные контейнеры.
