# Команды урока 2

Краткий список команд из [лекции](lesson.md). Можно копировать в терминал.

## Проверка

```bash
docker version
```

Показывает версию клиента и сервера. Должны быть блоки `Client` и `Server`. Если `Server` нет — Docker Desktop ещё не запущен.

## Образы

```bash
docker pull hello-world
```

Скачивает образ с Docker Hub. Если образ уже есть, команда проверит, что он актуален.

```bash
docker images
```

Список локальных образов. Поля: REPOSITORY, TAG, IMAGE ID, CREATED, SIZE.

```bash
docker rmi hello-world
```

Удаляет образ. Без тега ищется `hello-world:latest`. Если образ ещё используется контейнером, сначала удалите контейнер.

```bash
docker rmi имя-образа:тег
```

Удаляет образ с явным тегом, например `docker rmi python:3.12-slim`.

## Запуск контейнера

```bash
docker run hello-world
```

Создаёт **новый** контейнер из образа и запускает его. Если образа нет локально, Docker сам скачает его. Без тега подставляется `latest`. Каждый повторный `run` — это ещё один контейнер, а не перезапуск старого.

```bash
docker run --name hw hello-world
```

То же самое, но контейнеру задаётся имя `hw`. Имена должны быть уникальными.

```bash
docker run --rm hello-world
```

Запускает контейнер, ждёт завершения программы и удаляет контейнер. Образ при этом остаётся.

## Просмотр контейнеров

```bash
docker ps
```

Только запущенные контейнеры (`Up`). После `hello-world` список часто пустой: программа уже завершилась.

```bash
docker ps -a
```

Все контейнеры, включая остановленные (`Exited`). Поля: CONTAINER ID, IMAGE, COMMAND, CREATED, STATUS, PORTS, NAMES.

## Повторный запуск и остановка

```bash
docker start hw
```

Запускает уже существующий контейнер по имени или CONTAINER ID. Новый контейнер не создаётся.

```bash
docker start -i hw
```

Запуск с флагом `-i` (`--interactive`) — подключает ввод к терминалу.

```bash
docker start -ai hw
```

`-a` (`--attach`) показывает вывод в консоли, `-i` подключает ввод. По умолчанию `start` работает в фоне и ничего не печатает.

```bash
docker stop hw
```

Корректно останавливает работающий контейнер. Для `hello-world` обычно не нужна: программа завершается сама.

```bash
docker kill hw
```

Останавливает контейнер принудительно, если `stop` не справляется.

## Удаление

```bash
docker rm hw
```

Удаляет остановленный контейнер по имени или идентификатору.

```bash
docker rm -f hw
```

Удаляет контейнер, даже если он ещё работает.

```bash
docker container prune
```

Удаляет все остановленные контейнеры. Запущенные не трогает. Нужно подтверждение: `y` и Enter.
