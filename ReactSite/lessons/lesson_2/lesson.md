# Урок 2. Базовые команды работы с образами и контейнерами

Ролик: [#2. Базовые команды работы с образами и контейнерами](https://rutube.ru/video/06e29c6561aa62bf15faae7010921a48/)
Плейлист: [Docker для начинающих](https://rutube.ru/plst/859340/)

В уроке 1 вы запустили готовый образ `hello-world`. Теперь соберём **свой** образ и контейнер: консольный Hello World на Python и Java, веб-сервер на Node.js и статическую страницу на nginx.

Цель урока — по шагам, переписывая команды в терминал, получить работающий контейнер с вашим приложением.

Перед началом Docker Desktop должен быть запущен. Проверка:

```bash
docker version
```

Должны быть блоки `Client` и `Server`. Если Server нет — откройте Docker Desktop и дождитесь запуска движка.

Разработчики со всего мира могут выкладывать свои образы на [Docker Hub](https://hub.docker.com/).

Например, в поисковике вы можете ввести нужный вам язык или фреймворк и получите множество сборок с разными версиями.

Попробуйте найти классический образ для ознакомления `hello-world`. На его страничке вы можете найти команду для скачивания:

```bash
docker pull hello-world
```

Откройте терминал и перепишите команду. Вы увидите проверку на наличие образа и дальнейшее его скачивание. Далее в Docker Desktop во вкладке Images можно увидеть скачанный образ. Ту же самую информацию мы можем получить через терминал с помощью команды:

```bash
docker images
```

В списке должна быть строка `hello-world`. Команда показывает несколько полей: имя образа (REPOSITORY), тег (TAG), идентификатор (IMAGE ID), дату (CREATED) и размер (SIZE).

Примечание при запуске контейнера: если его нет, Docker автоматически попытается его найти и скачать.

### Теги

Отдельно стоит упомянуть теги. У каждого образа есть тег — это метка версии. Если тег не указать, Docker подставляет `latest`. Полное имя выглядит как `имя:тег`, например `hello-world:latest` или `python:3.12-slim`.


## Запускаем контейнер

С помощью команды:

```bash
docker run имя-образа
```

В данном случае — `hello-world`. Как мы помним, без указания тега автоматически проставится `latest`, то есть это то же самое, что `docker run hello-world:latest`.

```bash
docker run hello-world
```

После выполнения создастся контейнер. Он отобразится в Docker Desktop во вкладке Containers. Контейнер `hello-world` печатает текс а точнее результат выполнения программы и сразу завершается — в списке он будет со статусом Exited, это нормально.

Ту же информацию можно увидеть в терминале. `docker ps` показывает только запущенные контейнеры, поэтому после `hello-world` список может быть пустым. Все контейнеры, включая остановленные позволит отобразить флаг -a:

```bash
docker ps -a
```
 
Разберём поля, которые мы видим в терминале:

- **CONTAINER ID** — короткий идентификатор контейнера. По нему можно обращаться к контейнеру в других командах (`docker stop`, `docker rm`, `docker logs`).
- **IMAGE** — образ, из которого создан контейнер, например `hello-world`.
- **COMMAND** — команда, которая запускается внутри контейнера. 
- **CREATED** — когда контейнер был создан.
- **STATUS** — состояние: `Up` (работает) или `Exited` (завершился). У `hello-world` будет `Exited (0)` — код `0` значит, что программа завершилась без ошибки.
- **PORTS** — какие порты проброшены наружу. У `hello-world` это поле пустое: контейнер ничего не слушает.
- **NAMES** — имя контейнера. Если не задать своё через `--name`, Docker придумает случайное, вроде `funny_einstein`.
 
Важное примечание: `docker run` каждый раз создаёт **новый** контейнер — даже если такой же уже есть в списке. Повторный `docker run hello-world` не перезапустит старый контейнер, а добавит ещё один. В `docker ps -a` появятся несколько строк с одним образом, но разными CONTAINER ID и NAMES.

При этом создавать контейнеры с одинаковыми именами нельзя. Если задать имя через `--name` и такое имя уже занято, Docker выдаст ошибку. Без `--name` конфликт не возникнет: Docker каждый раз придумает новое случайное имя.
 
### Для запуска существующиго контейнер

Нужно воспользоваться командой `docker start` с указанием имени или идентификатора:


```bash
docker start имя-или-id
```
Полный пример:

1. Создайте контейнер с понятным именем:

```bash
docker run --name hw hello-world
```

2. Запустите этот же контейнер ещё раз:

```bash
docker start -i hw
```

3. Проверьте список — контейнер один, с именем `hw`:

```bash
docker ps -a
```

По умолчанию Docker запускает контейнер в фоновом режиме, поэтому он не выводит информацию в консоль.

Флаг `-i` (`--interactive`) подключает ввод контейнера к вашему терминалу. Чтобы увидеть **вывод** программы при `docker start`, нужен ещё флаг `-a` (`--attach`). Без них приветствие `hello-world` в терминале не появится.

Часто оба флага ставят вместе:

```bash
docker start -ai hw
```

Программа в контейнере `hw` завершается сама по себе, поэтому ей не требуется команда остановки. Если вы будете иметь дело с цикличной программой, которую нужно остановить, воспользуйтесь аналогичной командой:

```bash
docker stop имя-или-id
```

Например: `docker stop hw`.
  
Также, если команда `stop` по каким-то причинам не может остановить контейнер, можно воспользоваться командой `docker kill`:

```bash
docker kill имя-или-id
```

`docker stop` просит программу завершиться корректно и немного ждёт. `docker kill` останавливает контейнер сразу, принудительно.
 


## Удаление контейнера

К данному моменту вы могли запустить несколько контейнеров,создание которых  как правило занимают место на накопителе. Удалить их вы можете с помощью Docker Desktop. Тем не менее необходимо знать, как это можно делать через консоль с помощью команды, в которой указываем либо имя, либо идентификатор:

```bash
docker rm имя-или-id
```

Например: `docker rm hw`. Контейнер должен быть остановлен. Если он ещё работает, сначала `docker stop`, либо `docker rm -f имя-или-id`.

Также можно удалить все неработающие контейнеры с помощью команды:

```bash
docker container prune
```

Docker спросит подтверждение — нажмите `y` и Enter. Удалятся только остановленные контейнеры (`Exited`), запущенные не тронет.

После удаления контейнеров мы можем удалить ненужные образы с помощью команды:

```bash
docker rmi имя-образа
```

Например: `docker rmi hello-world`. Если образ ещё используется контейнером, сначала удалите контейнер.

### Примечание

Если `docker rmi hello-world` выдаст ошибку, скорее всего на компьютере нет образа с таким именем и тегом. Без указания тега Docker подставляет `latest`, то есть команда ищет `hello-world:latest`. Если вы хотите удалить образ с конкретным тегом, его нужно явно указать:

```bash
docker rmi имя-образа:тег
```

Например: `docker rmi python:3.12-slim`. Список локальных образов и их теги можно посмотреть через `docker images`.
 


Напоследок рассмотрим случай, когда нам нужно запустить контейнер, дождаться, чтобы он отработал, и после этого он не занимал место. Для этого воспользуемся командой:

```bash
docker run --rm hello-world
```

Она при необходимости скачает образ, запустит контейнер, дождётся завершения программы и после этого удалит контейнер. Образ `hello-world` при этом останется на компьютере.
