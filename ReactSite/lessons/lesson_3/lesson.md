## Первй образ из Dockerfile 

Перейдём к делу. Для создания образа нам потребуется создать директорию и открыть IDE по её адресу. В поле, где отображается иерархия файлов, создаём файл с названием `Dockerfile`.

Это — текстовый рецепт: из какого базового образа стартовать, какие файлы положить внутрь, какую команду запускать.
Из `Dockerfile` формируется образ, а из образа — контейнер.

С ним рядом создадим ещё один файл, который будет служить примером собственной программы на языке программирования Python, с именем `main.py`.
В нём пропишем скрипт, состоящий из одной строки: 

```python
print("Hello World from Python in Docker")
```

Мы не будем разбирать преимущества того или иного языка программирования. В дальнейшем вы сможете самостоятельно создать образ с применением языка программирования, который изучаете. А сейчас перейдём непосредственно к самому Dockerfile.


### Команды Dockerfile, которые понадобятся

| Инструкция | Зачем |
|---|---|
| `FROM` | базовый образ (готовая ОС + runtime языка) |
| `WORKDIR` | рабочая папка внутри контейнера |
| `COPY` | скопировать файлы с компьютера в образ |
| `RUN` | выполнить команду на этапе сборки (например, `javac` или `npm install`) |
| `EXPOSE` | подсказка, какой порт слушает приложение |
| `CMD` | команда, которая запускается при старте контейнера |

Осталось правильно прописать команды в самом `Dockerfile`.
Из [Docker Hub](https://hub.docker.com/search) нам нужно взять образ с интерпретатором Python. Для примера я укажу версию `python:3.12-slim`.
Таким образом первая строка в Dockerfile будет выглядеть так:

```dockerfile
FROM python:python:3.12-slim
```
В добавленной операционной системе создадим подкаталог с именем `app` и сделаем его рабочим с помощью команды:

```dockerfile
WORKDIR /app
```

Команда создаст каталог, если его нет, и сделает его рабочим, то есть текущим.

После этого нам нужно скопировать файл, который мы создали ранее, в сам каталог. Для этого пропишем команду:

```dockerfile
COPY . .
```

В команде мы указываем, откуда копируем и куда. Если укажем две точки — `. .` — скопируются все файлы из текущего каталога в рабочий каталог образа.
 
Наконец, последней строкой мы укажем команду запуска, которая должна выполниться при запуске самого контейнера:

```dockerfile
CMD ["python", "main.py"]
```
 
Мы обращаемся к интерпретатору Python и передаём ему в качестве аргумента имя файла, который хотим запустить.

Итоговый файл выглядит так:

```dockerfile
FROM python:3.14.7-alpine

WORKDIR /app
COPY . .

CMD ["python", "main.py"]
```

После того как мы всё прописали, осталось собрать образ. В терминале, находясь в папке с `Dockerfile`, прописываем команду:

```bash
docker build -t hello-python .
```

`-t` задаёт имя образа, точка в конце — текущая папка, из которой берётся `Dockerfile`.
 


Теперь по этому образу можно создать контейнер и запустить его ровно так же, как мы это делали в прошлом уроке, с помощью команды:

```bash
docker run hello-python
```

Если хотите, чтобы контейнер удалился после завершения программы, добавьте `--rm`:

```bash
docker run --rm hello-python
```
